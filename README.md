 # QuantBloc

  **On-chain analytics for Solana memecoin traders (pump.fun and PumpSwap).** Find the wallets worth following, check what copying them would really have made, and read any token before you buy.

  🌐 https://quantbloc.com

  ## What you can do on QuantBloc

  - **The Base**: every wallet seen trading pump.fun tokens, with your own filters, columns and sorting (PnL, multiples, rug rate, activity...). https://quantbloc.com/base
  - **Wallet pages**: every trade of a wallet, one by one, over its whole history.
  - **Copy-trading backtest**: replay what a copier would really have made by following a wallet at the same block or 2 blocks later, with real fees. https://quantbloc.com/methodology
  - **Tracker lists**: weekly wallet lists (KOLs, profitable wallets, gem hunters, whales) ready to import into GMGN or Axiom. https://quantbloc.com/tracker-lists
  - **Token list and token pages**: creator, dev and funder, first block, bundle, early buyers, top traders, peak and rug. https://quantbloc.com/token-list
  - **Market weather**: the state of the pump.fun market today. https://quantbloc.com/weather
  - **AI connector**: ask Claude or ChatGPT about any wallet or token in plain language. https://quantbloc.com/connector
